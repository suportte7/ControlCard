# Gerenciador de Despesas e Compras (v2)

Aplicação web desenvolvida para controle financeiro pessoal, otimizada para praticidade, autonomia e backup seguro de dados.

## 🚀 Funcionalidades da v2

- **Lançamento Rápido e Organizado:** Interface intuitiva para registro de despesas e compras diárias.
- **Push Diário Programado:** Alertas automáticos em horário fixo configurado para lembrar você de registrar as compras do dia.
- **Backup Multiformato Robusto:** 
  - Sincronização com planilha viva.
  - Exportação em formato **JSON**.
  - Exportação em formato **HTML** para visualização e preservação de registros a longo prazo.
- **Histórico de Alterações:** Rastreabilidade completa das versões e melhorias implementadas.
